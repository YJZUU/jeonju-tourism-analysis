# 🏙️ 전주 관광 활성화 분석
전주시 공모전 | 장려상 (3위) | 2023.04 ~ 2024.07

## 📌 프로젝트 개요

전주시 관광객의 90.6%가 무박 여행으로,
인당 소비액(4,929원)이 경북·충남 대비 현저히 낮은 문제를 데이터로 진단하고

**체류형 관광 유도**를 위한 정책을 제안한 공모전 프로젝트입니다.

## 🔍 핵심 발견

- 전주 무박 비율 **90.6%** vs 타 지역 평균 80%
- 평균 체류 시간 **3.99h** (경북 6.97h, 충남 6.72h 대비 현저히 낮음)
- 인당 소비액 **4,929원** (충남 7,163원 대비 약 31% 수준)
- 숙박률 - 소비액 선형 회귀: **R² = 0.83**
- 숙박률 10%p 개선 시 소비액 **약 16.3억 원 증가** 예측

## 📊 분석 흐름

1. **현황 분석** — 전주 vs 경북·충남 무박 비율·체류 시간·소비액 비교
2. **인과 검증** — 숙박률 → 소비액 선형 회귀 (R²=0.83)
3. **텍스트 마이닝** — 전국 문화 축제 데이터 워드클라우드 시각화
4. **SWOT 분석** — SO/WT 전략 도출
5. **정책 제안** — 야간 체험 축제·중간 거점 설계·먹거리 가격 통일화
